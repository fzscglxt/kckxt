MRP流程：1. 读取客户需求（逐期）→ 2. 扣减库存+计划接收 → 3. 成品级平衡（净需求→生产计划）→ 4. 按BOM展开下一层子件毛需求 → 5. 子件级平衡（自制→生产 / 外购→采购）→ 6. 是否还有下级BOM？（循环）→ 7. 输出汇总。
公式：毛需求 = 父项计划量 × 单位用量 / 成品率 + 固定损耗；净需求 = 毛需求 + 安全库存 - 期初库存 - 计划接收；排产天数 = 有班产时 ceil(净需求/班产)，无班产时用工序周期；下达日期 = 需求日期 - 排产天数；子件需求日期 = 父件下达日期。
